Overview

The Resume Builder is a web application that helps you create professional resumes by:

  • Managing your job titles and work history
  • Organizing your experience statements
  • Tracking your technical skills
  • Combining everything into a polished resume

File Setup

The application requires three text files in the same directory as the application:

1. titles.txt

Format: Title | Company | StartDate-EndDate

Example:
Software Engineer | Google | 2020-2023
Senior Developer | Microsoft | 2018-2020

2. experience.txt

Format: One experience statement per line

Example:
Led development of machine learning pipeline
Reduced system latency by 40% through optimization

3. skills.txt

Format: One skill per line

Example:
Python
SQL
AWS

Using the App

1 Select Job Titles

Your job titles are automatically loaded from titles.txt. Each job title shows the company and dates.

2 Add Experiences

Click experiences in the Experience Pool to select them, then click "Add Experience" under the relevant job title to add them.

3 Select Skills

Click on skills in the Technical Skills section to select them. Selected skills will be highlighted.

4 Build Resume

Click the "Build Resume" button to generate your resume with all selected items.

Tips & Tricks

  • Experience Selection: You can select multiple experiences before adding them to a job title.
  • Skills Organization: Skills are automatically sorted alphabetically for easy finding.
  • Resume Review: You can remove experiences from job titles after adding them using the 'X' button.
  • Multiple Attempts: You can rebuild your resume multiple times with different selections.

Troubleshooting

  • Verify that all text files are in the same directory as the application
  • Check that the files have the correct format
  • Ensure the files are saved with UTF-8 encoding

  • Make sure titles.txt uses the correct delimiter (|)
  • Check for extra spaces at the beginning/end of lines
  • Verify date formats in titles.txt (YYYY-YYYY)
